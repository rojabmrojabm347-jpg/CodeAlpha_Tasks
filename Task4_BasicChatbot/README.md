## 📌 Project Overview

The **Basic Chatbot** is a simple rule-based conversational application developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through text-based conversations and provides predefined responses based on user input.

It uses conditional statements, functions, loops, and basic string operations to understand user messages and generate appropriate replies.

## 🎯 Project Objectives

- Develop a simple rule-based chatbot using Python.
- Understand conditional statements and functions.
- Implement loops for continuous conversations.
- Process user input and generate predefined responses.
- Store and display conversation history.

## ✨ Features

- **Interactive Conversations:** Communicates with users through text input.
- **Predefined Responses:** Responds to greetings and common questions.
- **Case-Insensitive Input:** Recognizes messages regardless of letter case.
- **Multiple Responses:** Handles greetings, thanks, name-related questions, and more.
- **Continuous Chat:** Allows users to interact until they choose to exit.
- **Conversation History:** Stores and displays messages exchanged during the session.
- **Exit Option:** Ends the conversation using `bye` or `exit`.

## 💬 Available Chatbot Commands

| User Input | Chatbot Response |
|---|---|
| hello / hi | Welcomes the user |
| how are you | Responds about its well-being |
| what is your name | Introduces itself |
| what can you do | Explains its capabilities |
| thank you / thanks | Responds politely |
| good morning | Gives a morning greeting |
| good night | Gives a night greeting |
| who created you | Explains that it was created using Python |
| bye / exit | Ends the conversation |

## 🚀 How to Run the Project

### Prerequisites

- Python 3 installed on your computer.
- Visual Studio Code or another Python-supported IDE.

### Step 1: Clone the Repository

```bash
git clone https://github.com/rojabmrojabm347-jpg/CodeAlpha_Tasks
```

### Step 2: Navigate to the Project Folder

```bash
cd Task4_BasicChatbot
```

### Step 3: Run the Chatbot

```bash
python chatbot.py
```

### Step 4: Start Chatting

Enter your messages in the terminal and interact with the chatbot.

Type `bye` or `exit` to end the conversation.
